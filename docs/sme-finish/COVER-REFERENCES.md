## Patterns used
1. Frameless browser (hairline bar, no laptop/desk), tilted in 3D and bleeding off the frame so the UI is big.
2. One key UI element lifted out of the screen as a floating layer with a real shadow (the approval row) = the story in one glance.
3. Phone overlapping the web view in depth, angled with the same vanishing point.
4. Single brand field (coffee / cream) + low-alpha deep-green glow behind the product + 2% grain.
5. Motion = slow parallax between layers (float lifts more than the window), not camera shake.
